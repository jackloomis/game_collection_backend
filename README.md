## Project Overview
Project backend consists of a REST API which accesses A PostgreSQL database containing the user's video game collection.
The API enables retrieving, adding, and modifying game information.

### Required Technologies
- Node.js
- Express
- PostgreSQL
- `pg` for database connectivity
- `dotenv` for environment variables
- CORS to allow frontend requests

## Installation and Setup

### Prerequisites
- Node.js
- PostgreSQL
- Git

### Clone Repository
`git clone https://github.com/jackloomis/game_collection_backend`
`cd game_collection_backend`

### Install Dependencies
`npm install`

### Environment Variables
The backend uses a `.env` file for PostgreSQL database information.

Create a `.env` file in the root directory using the following variables:
- `DB_USER=`
- `DB_HOST=`
- `DB_PASSWORD=`
- `DB_NAME=`
- `DB_PORT=5432`
IMPORTANT: Root directory should also contain a `.gitignore` file that includes `.env` to avoid uploading database credentials to GitHub.

### Start Server
`npm start`

Local API runs on port 8003.

## API Documentation

### Base URL
`https://game-collection-backend-arno.onrender.com/api/v1/game_collection`

### GET /api/v1/game_collection
Retrieves list of games from the database.

Example response:

```json
[ 
    { 
        "id": 1, 
        "title": "Example Game", 
        "genre": "RPG", 
        "system_id": 1, 
        "status_id": 1, 
        "rating": 5 
    } 
]
```

### GET /api/v1/game_collection/id/:id
Retrieves an individual game by ID number.

Example request:

`/api/v1/game_collection/id/1`

Example response:

```json
[ 
    { 
        "id": 1, 
        "title": "Example Game", 
        "genre": "RPG", 
        "system_id": 1, 
        "status_id": 1, 
        "rating": 5 
    } 
]
```

### POST /api/v1/game_collection
Add a new game to the database.

Example body:

```json
{
    "title": "Example Game",
    "genre": "RPG",
    "system_id": 1,
    "status_id": 1,
    "rating": 5
}
```

Example response (ID auto-generated by database):

```json
[
    {
        "id": 1,
        "title": "Example Game",
        "genre": "RPG",
        "system_id": 1,
        "status_id": 1,
        "rating": 5
    }
]
```

### PUT /api/v1/game_collection/id/:id
Modify an existing game by ID number.

Example request:
`/api/v1/game_collection/id/1`

Example body:

```json
{
    "title": "Updated Game",
    "genre": "Adventure",
    "system_id": 2,
    "status_id": 2,
    "rating": 4
}
```

Example response:

```json
[ 
    { 
        "id": 1, 
        "title": "Updated Game",
        "genre": "Adventure",
        "system_id": 2,
        "status_id": 2,
        "rating": 4
    } 
]
```

## Database Setup
A PostgreSQL database stores the game collection using the following table columns:

### Games
- `id`: Integer, primary key, NOT NULL
- `title`: Varchar(50), NOT NULL
- `genre`: Varchar(50)
- `system_id`: Integer, foreign key referencing `systems`, NOT NULL
- `status_id`: Integer, foreign key referencing `statuses`, NOT NULL
- `rating`: Integer

### Systems
- `system_id`: Integer, primary key, NOT NULL
- `system_name`: Varchar(50), NOT NULL

### Statuses
- `status_id`: Integer, primary key, NOT NULL
- `status`: Varchar(20), NOT NULL

After creating the database and tables, configure the connection using variables from the `.env` file.

## Authentication and Security
The API does not currently require user authentication such as JWT, OAuth, or API keys.

Environment variables are used to separate database credentials from source code. The `.env` file should not be committed to the repository.

CORS allows requests so the frontend can communicate with the API.

## Deployment Guide
The backend is deployed with Render.

The deployed API is located at: `https://game-collection-backend-arno.onrender.com`

To make changes, commit and push code to the GitHub repository:

`git add .`
`git commit -m "Describe your changes"`
`git push origin dev`

Then create a pull request describing your changes. After the changes are merged to the `main` branch, Render will automatically deploy the updated backend.
